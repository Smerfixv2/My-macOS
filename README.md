# macOS Personal Website

A personal website designed to look and feel like a small macOS desktop.

Instead of using a traditional portfolio layout, the website works like an interactive desktop. Visitors can open windows, click icons, explore different sections and discover hidden elements.

## ✨ What's on the website

- 🖥️ macOS-style desktop
- 📁 Projects section
- 👤 About Me section
- 🕐 Now page showing what I'm currently working on
- 🗑️ Trash
- 🪟 Draggable and closable windows
- 🕒 Live clock
- 🔍 Interactive desktop icons
- 🔒 Hidden secrets and easter eggs

## 🛠️ Built with

- HTML
- CSS
- JavaScript

No website builder or portfolio template was used. Everything was built from scratch.
